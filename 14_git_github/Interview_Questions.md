# Git Interview Questions

---

## Q1. What is Git?

Answer

Git is a Distributed Version Control System used to track changes in source code.

---

## Q2. What is GitHub?

Answer

GitHub is a cloud platform used for hosting Git repositories.

---

## Q3. Difference between Git and GitHub?

Answer

Git

- Local software
- Tracks project history

GitHub

- Cloud platform
- Stores repositories online

---

## Q4. What is Version Control?

Answer

Version Control is the process of maintaining multiple versions of the same project.

---

## Q5. What is a Repository?

Answer

A Repository is a project folder managed by Git.

---

## Q6. What is the Working Directory?

Answer

The Working Directory is where files are created and modified.

---

## Q7. What is the Staging Area?

Answer

The Staging Area temporarily stores selected changes before committing.

---

## Q8. What is a Commit?

Answer

A Commit is a snapshot of the project at a particular point in time.

---

## Q9. What does git status do?

Answer

Shows the current state of the repository.

---

## Q10. What does git add . do?

Answer

Stages all new and modified files.

---

## Q11. What does git commit do?

Answer

Creates a checkpoint containing staged changes.

---

## Q12. What does git push do?

Answer

Uploads commits to GitHub.

---

## Q13. What does git pull do?

Answer

Downloads the latest changes from GitHub.

---

## Q14. Why do companies use Git?

Answer

- Version Control
- Team Collaboration
- Backup
- Change Tracking
- Rollback Support
