# Git Commands

---

## git status

Purpose

Displays the current status of the repository.

Example

git status

---

## git add .

Purpose

Stages all modified and new files.

Example

git add .

---

## git commit -m "message"

Purpose

Creates a new checkpoint (snapshot).

Example

git commit -m "Added Git Basics"

---

## git push

Purpose

Uploads local commits to GitHub.

Example

git push

---

## git pull

Purpose

Downloads the latest changes from GitHub.

Example

git pull

---

## git log

Purpose

Displays commit history.

Example

git log
